Template file and processing options

By default, the website loads template.zip from the same GitHub Pages folder as this file. The ZIP must contain a .docx template (or a DOCX package directly). You can optionally choose a local ZIP or DOCX file. Processing is performed in your browser; project data is saved only in this browser until you clear it.

Dates display as Month Day, Year (for example, October 27, 2026). Placeholder matching is case-insensitive, including placeholders split across Word runs. Existing Word formatting is retained where possible.

This tool generates a draft report. Review all replacement text, conditional deletions, formatting, and footnotes before issuing a final Phase I ESA.
